# Pack Paradox (fan work)

Ícone e paleta inspirados na heroína **Paradox** (*Deadlock*) / estética Pulse Grenade, **sem** usar assets oficiais ripados do jogo.

- `app-icon.png` — Pulse Grenade (fan), 128×128, cabeçalho do app com pack Paradox.
- `tray.png` — **mesmo desenho** que `app-icon.png`, redimensionado para 48×48 (bandeja). Ao trocar o ícone, regenere o tray a partir do app-icon.
- `notify-alert.mp3` — som ao disparar aviso de lembrete (pré-horário ou na hora).
- `reminder-saved.mp3` — som ao **criar** um lembrete (Salvar).
- `notify.oga` — legado; usado só se `notify-alert.mp3` não existir.

Não é produto licenciado pela Valve / desenvolvedores de *Deadlock*.
