# Pack Paradox (fan work)

Ícone e paleta inspirados na estética sci-fi azul do universo *Apex Legends* (grenade Paradox / Pulse), **sem** usar assets oficiais ou ripados do jogo.

- `tray.png` — desenho original para a bandeja do sistema (anel/pulso azul, legível em ~22–24px).
- `notify.oga` — opcional; se presente, o Reminder usa como som de notificação deste pack.

Não é produto licenciado pela EA / Respawn.
